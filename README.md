# CITYLINE · 尸潮围城

一个 2.5D（45° 轴测）城市战争沙盘的 Web 原型：128 名普通士兵、数千感染体、一条可以被画出来的战线。

不是塔防。没有炮塔、没有英雄技能、没有科技树。玩家唯一的手段是**把一条线画在地图上**，然后看着这条线在尸潮下弯曲、破洞、崩塌，或者撑住。

```bash
npm install
npm run dev            # 打开终端里打印的地址（默认 http://localhost:5173，被占用时自动顺延）
```

只想直接玩：双击打开根目录的 **`standalone.html`**（单文件，135 KB，无需服务器）。

## 1. 操作

| 操作 | 说明 |
| --- | --- |
| **左键拖拽** | 框选士兵（`Shift` 追加选择） |
| **双击** | 选中该处集群并跟随镜头 |
| **1 / 2 / 3 / 4 / 5** | 切换指令：框选 / 守住阵线 / 推进 / 后撤 / 强行军 |
| **选好指令后左键拖拽** | 在地图上画出那条线，松开即下令 |
| **右键点击** | 简单移动（松散队形） |
| **右键拖拽 / 中键拖拽 / 空格+拖拽** | 平移镜头 |
| **WASD / 方向键** | 平移镜头 |
| **滚轮** | 连续缩放，缩放中心是鼠标所在的世界位置 |
| **Q / E** | 旋转整个 2D 战场 |
| **H** | 回到全城战略视角 |
| **A** | 全选守军 · **R** 呼叫增援（3 次） |
| **空格** | 暂停 · **Esc** 取消选择 |

三条指令的差别不只是颜色：

- **守住阵线** —— 士兵自行跑到线上、拉开间距、补缺口，不追击。这是默认的防御姿态。
- **推进** —— 沿阵线法向缓慢压上，边打边走；接触时自动减速。
- **后撤** —— 优先脱离接触，走到目标线后重新组阵。
- **强行军** —— 快速转移，不恋战，只绕行不进攻。

## 2. 玩法结构

城市被划分为 9 个街区（住宅区、医疗区、商业区、中央政务区、中央公园、老城区、仓储带、工业区、东站前区）。
道路不是棋盘：有主干道、次级街道、T 型路口、斜切老城区的通道、仅容 20 人据守的窄巷，以及一个完全无法据守的公园。
高架铁路桥横穿东北城区，桥墩之间是天然的漏斗。

**三个关键节点**：市政厅、医疗中心、撤离区。全部失守即失败；坚持 13 分钟即胜利。
只守住其中一个也算赢——放弃两个区、把 128 人收缩到最后一个区，是一条真实可行的打法。

尸潮压力是动态生成的（`src/simulation/director.ts`）：

| 时间 | 事件 |
| --- | --- |
| 00:00 | 外围出现零散感染者 |
| 00:40 | 北侧出现第一支尸群（+240） |
| 01:45 | 东侧商业区遭遇大规模尸潮（+340） |
| 02:50 | 西南出现疾行者（+150，45% 为 Runner） |
| 03:55 | 重躯接触（+90，10% Brute） |
| 05:00 起 | 多方向同时施压，规模逐级抬升到 3000+ |

除此之外还有一条永不停歇的渗流：控制器每帧根据时间、当前存活守军数与各方向的“安静程度”选择投放点，
所以压力总是出现在看起来最安全的地方。

## 3. 三个 Zoom 层级

| 镜头 | 看到什么 |
| --- | --- |
| **战略层** (0.10x) | 整座城市的地块结构、尸潮流向、人类战线、危险街区标记 |
| **战术层** (1–2x) | 几十到几百个单位交战、防线的形状、街道里的拥堵 |
| **近景** (9–11.5x) | 一个士兵的头盔、武器、步态、射击动作；一个僵尸的驼背和前伸的手臂 |

角色不是点，也不是圆：每个人物由 3D 骨架摆姿后用**与游戏相机完全相同的轴测投影**烘焙成精灵，
所以八方向、五种视角的手绘感是一致的，而且轮廓、遮挡和体积都是真的。

## 4. 工程结构

```
src/
  core/        math / config / spatial hash
  map/         city.ts（城市生成）  nav.ts（导航网格 + 流场）
  entities/    anim.ts（动画契约）  types.ts（单位表）
  simulation/  world.ts  ai.ts  combat.ts  orders.ts  director.ts  sim.ts
  renderer/    renderer.ts  camera.ts  buildings.ts  textures.ts  atlas.ts  figures.ts  sprites.ts  glutil.ts
  input/       input.ts
  ui/          hud.ts  style.css
  main.ts      启动、固定步长主循环、自动化接口
```

渲染层与模拟层完全解耦：模拟只维护数组与数值，渲染每帧从世界状态重建实例缓冲，两者之间没有回调。
详见 `docs/ARCHITECTURE.md`。

| 开局 · 战术视角 | 303 | 0 | 59.9 |
| 开局 · 近景 9.5x | 349 | 0 | 60.0 |

绘制批次与负载无关：地面 1 次、全部建筑 1 次（约 40 万顶点静态 VBO）、道具 1 次、单位 2 次（实体 + X 光轮廓）、特效 1 次。
30400 个 96×96 单位的精灵与 800 栋建筑不会带来任何额外的 draw call。

## 6. 自动化接口

游戏把内部状态挂到 `window.__CITYLINE__`，便于无头试玩与回归测试：

```js
__CITYLINE__.snapshot()            // 时间/守军/感染体/伤亡/目标血量/FPS
__CITYLINE__.step(60)              // 不等真实时间，直接推进 60 秒模拟
__CITYLINE__.selectRect(x0,y0,x1,y1)  // 屏幕坐标框选
__CITYLINE__.issue('hold', ax,ay,bx,by)  // 画一条防线
__CITYLINE__.contact()             // 当前最激烈的接触点
__CITYLINE__.orderStats()          // 每条命令的人数、槽位、平均到位距离
```

```bash
npm run shots         # 无头浏览器真实试玩，产出 6 张验收截图到 docs/shots/
npm run perf          # 分阶段 FPS 基准（结果写入 docs/play-perf.json）
npm run fullgame      # 打完整一局并输出每分钟战况
npm run typecheck     # tsc --noEmit
npm run build:standalone   # 重新生成单文件 standalone.html
```

## 8. 三轮返工摘要

1. **路网重建**：九个互相重叠、各自转向的街区街网 → 单一全局格网 + 街区抑制格线；
   删掉全部随机角度支路；占位检测从 16 单位栅格换成精确 AABB。
   建筑数 8 → **922**。
2. **三个运行期 bug**：命令不生效（order 没进 world.orders）、重开一局崩溃（空间哈希没清）、
   目标点标记悬浮（overlay 画在建筑之上）。
3. **视觉**：目标圈烘焙进地面；屋顶杂物改矮改成设备；建筑密度下调让楼后的单位可见；
   僵尸配色压暗；**单位改为深度测试 + X 光轮廓**，既被建筑正确遮挡、又不会消失在楼后、
   也不会再出现「站在屋顶上」的假象。

4. **比例 / 密度 / 节点方块**（第二轮反馈）：删掉节点半径上那 24 个既浮空又穿模的混凝土方块，改成地面涂装 + 沙袋掩体；
   全城从「真实比例的高层城市」压到中低层（最高 51 m），地块填充率 0.70 → 0.58、空地率 16% → 26%，
   单位世界高度 9.2 → 10.4、远景最小像素 4.2 → 6.0。人在 2x 镜头下的屏幕占比提升约 1.8 倍。
